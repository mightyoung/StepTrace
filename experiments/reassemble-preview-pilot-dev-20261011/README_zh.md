## 待审区间队列

[复核队列](review_queue.csv) 只保存任务提供的候选线索，并标为未核验。它不是帧清单、视频观察记录或 AI 预标注。MPL 的时间点保持空值；AD 的 76–100 秒只作为宽候选窗口，不作为精确事件边界。只有在媒体变得可读后，才创建实际帧索引。

## 复核方案

1. 对每段展示片逐一核验文件大小和 SHA-256。任何差异均停止该素材，不换版本或来源。
2. 用现有 `ffprobe` 读取实际视频流、时间基和逐帧 PTS；不根据假定帧率推造源帧编号。每个导出帧记录源帧索引、原始 PTS、time base、PTS 秒值和像素尺寸。
3. 对每个候选变化保留事件前状态、首个可见变化、最后一个变化前帧、首个稳定后帧和片尾状态。事件时间以最后一个可确认前态到首个可确认后态组成区间；不把 `Prediction` 字幕或演示旁白当标注真值。
4. 原始帧只读保存在工作区媒体目录。遮字模型输入另存一份，仅以不透明色块盖住可见文字叠层，不修补/生成被遮挡像素。记录每个遮罩的原图坐标、尺寸、目标文字和派生文件 SHA；若没有叠层，则标记 `mask=none`。
5. 用户可查看的关键帧清单和联系表只引用原始帧，不覆盖原始图像。模型输入和原始帧用相同的源 PTS 与帧索引配对。

## 同前缀对照

以后如获准运行模型，每个截止点 `t` 的两个观察臂必须看到完全相同的帧、分辨率、时间范围和提示信息：

- **当前可见状态臂**：只记录截止点 `t` 可见的物体/关系及其可见性；不能从过去出现过推导当前仍连接或牢固。
- **过程证据臂**：记录同一前缀中观察到的动作、状态变化和不确定区间。历史上曾安装/提升的事实可保留为历史事件；当前关系需由截止点附近可见证据重新支持。

当前没有模型调用授权，也没有媒体输入，因此两臂输出、最终状态和过程证据均未生成。此准备包不计算成功率、准确率或机制增益。视频最多支持可见状态描述；机械牢固程度、扭矩、内部接触、精确物理脱开时刻及跨剪辑连续性均需其他证据。

## 限制

- 这两项是网站展示片候选，不等同于原始数据集样本、随机抽样或独立实验集。
- 用户提供的 MPL / AD 内容摘要尚未由本环境逐帧核验。
- 当前获取阻断只说明此云端环境无法建立到给定主机的 CONNECT 隧道，不表示源站拒绝、素材受限或许可不允许。
- 旧 IndEgo 原始帧映射及 H/F/HF 首答 JSON 仍然缺失；该缺口和旧实验状态保持不变。
