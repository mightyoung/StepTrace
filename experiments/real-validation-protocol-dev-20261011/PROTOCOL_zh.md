# StepTrace 最小真实验证协议

**版本**：`steptrace-minimal-real-validation/1.0` · **日期**：2026-10-11
**状态**：设计冻结；执行门关闭。样本分母、样本量、覆盖率匹配界值和功效均待真实样本清点后确定。本文件不是预注册结果，也不授权模型调用。

## 1. 目的与不变量

验证在同一真实 SOP 机会、同一可用帧前缀下，全图、局部图和时序记忆三种输入/更新方式对步骤完成判断有何差异。目标是减少错误的“步骤已完成”，同时报告拒判，不把更多 `unknown` 当作无条件改进。

三种概念必须分别记录：

- **当前直接关系**：仅当截止帧的目标接口可见、目标身份受支持时，才可记为当前直接支持或当前直接分离。
- **历史确认及当前适用性**：保留曾有证据支持的历史事实；当前延续只能另标 `conditional_history` 并列出假设。历史记录本身不等于当前仍连接。
- **过程步骤完成**：必须对照预先冻结的 SOP 步骤证据规则。端点外观或连接关系不能自动证明安装过程或步骤完成。

当接口在截止帧不可见、身份不确定/改变、可见证据互相冲突，或未观测间隔使必要假设无法核实时，当前直接关系必须为 `unknown`。若只知道明确分离，应输出分离并撤销旧记录的当前适用性，但保留历史记录。`unknown` 不代表断开；条件估计不应被下游压成无条件完成。

## 2. 三路配对对照与因果边界

每条评估机会固定一个来源事件、目标（host/part/interface）、SOP step ID、截止时点和帧前缀。三路均使用**完全相同的源帧 ID、时间戳和帧集合**（每帧均不晚于截止时点）；差异只在空间呈现与状态更新方式。

| 路径 | 输入与更新 |
|---|---|
| **全图批处理（主基线）** | 同一前缀中的全幅帧一次提供；每个截止点无跨样本持久状态。 |
| **局部图批处理（次要）** | 同一帧 ID 的目标/接口局部裁图一次提供；裁图规则、坐标来源、边界和缩放在看输出前冻结并留档，且只可依据当前截止前缀确定。不能因模型答错或看见未来帧而重裁。 |
| **时序记忆（主比较路径）** | 与全图路相同的全幅帧，按源时间顺序逐帧送入持久状态；每个截止点输出。事件开始时重置状态，不能读取未来帧、未来标签或后续回答。 |

三路共享同一目标锚点、SOP 指令、问题、输出 schema、模型版本/后端、解码参数和截止点。只允许上述空间/时序处理差异；若模型版本、参数或呈现轨迹无法核实，结果标为探索性，不作确认性归因。记录每路图像数、分辨率/裁图哈希、调用数、延迟和可得费用；不假定调用成本相等。

共同输出至少分列 `direct_relation`、`current_estimate` 与 `basis/assumptions`、历史记录 ID/适用性、`process_evidence`、`step_completion`、证据引用。条件连接不能直接映射为步骤完成；步骤证据映射须事前冻结。

同一机会须在三路全部运行，按机会配对比较。所有输入严格满足 `frame_time <= cutoff`；时序路在截止前逐帧因果更新。不得将相邻前缀拆入不同数据划分；划分单位是来源视频/物理装配事件，而不是帧或模型回答。样本抽取、目标、截止点和裁图在查看输出前冻结。

## 3. 主假设、指标与样本单位

**唯一主假设 H1**：在共同帧前缀和预设覆盖率匹配规则下，时序记忆路在真实挑战集中、经盲审裁定为“步骤未完成”的机会中，比全图批处理路产生更低的错误完成率。局部图路为次要/探索性比较。若时序路只靠增加拒判取得较低错误率，不支持 H1；须报告风险—覆盖率权衡。覆盖率匹配规则及允许差值须在独立校准集上冻结，不能在最终评估集调阈值。

- **主要指标：错误完成率** `FCR = 参考为 incomplete、系统输出 complete 的机会数 / 参考为 incomplete 的可评估机会数`。仅以冻结 SOP 规则和人工参考确定步骤标签；当前连接状态不替代该标签。
- **拒判覆盖率** `coverage = 系统给出 step_completion=complete 或 incomplete 的机会数 / 参考标签为 complete 或 incomplete 的可评估机会数`；`step_completion=unknown`、只给条件历史而未给步骤判定、缺答或格式无效均按拒判/无效输出另报。若把条件历史映射为 `step_completion=complete`，它就是完成声明：参考为 incomplete 时计入 FCR 分子，不能改算拒判。`abstention_rate = 1 - coverage`。覆盖率按三类反例分别列出，不与 FCR 合成一个分数。
- 人工参考为 `unknown` 的机会不进 FCR 分母；数量和原因单列。不得把未知真值当成正确负例或排除后隐藏。

反例富集集不是自然发生率样本；其 FCR 只描述本挑战集，不能当作部署总体发生率或普适准确率。

**最小标注单元**是一行 `(来源组, 物理事件, 目标 host/part/interface, SOP step ID, cutoff PTS/time_base)`，并登记：可用帧 ID 与哈希、当前关系参考（connected/disconnected/unknown）、身份（same/different/uncertain）、接口可见性/遮挡、过程是否被采到、步骤参考（complete/incomplete/unknown）、支持证据帧/区间及两位标注者和裁决状态。关系、过程证据与步骤完成是独立字段。

以机会配对，按来源视频/物理事件聚类报告；不能把帧、前缀或同一事件的多个目标当作独立样本。每类所需事件数、总分母、覆盖率匹配差值、区间精度和统计功效目前均为 **TBD**。在完成样本清点前不做功效承诺、显著性结论或普适增益表述。

## 4. 必须覆盖的真实反例与盲标

最终验证集必须含以下三类真实事件；每类数量待清点，不用合成例替代：

1. **遮挡但关系保持**：曾有直接确认，随后接口遮挡；只有视角/连续性足以裁定隐藏期间未分离的原视频，或独立参考，才能标为“保持”。接口完全不可见且无外部佐证时，单凭“没看到拆卸”不足以证明保持。
2. **真实拆卸/分离**：曾有直接确认，之后同一目标发生真实分离；标明分离时间边界与可支持该标签的帧/独立参考。若分离完全落在不可核验的遮挡区间，参考为 `unknown`，不得伪作真实负例。
3. **对象更换/身份变化**：旧目标离开、身份连续性断开，或被相似对象替换；旧连接历史不得转移给新对象。只有身份变化可由原视频/独立参考核实时才进入该类。

来源整理者可看完整视频挑选事件，但须在模型运行前冻结选择清单、曝光/划分和时间边界，不参加模型输出标注。每种标签流至少由两位独立标注者完成，均看不到方法分组、模型输出和主假设：前缀组只看截至各自 cutoff 的输入，标直接可见证据；全视频组可看完整、未剪辑原视频，标物理事件、身份和 SOP 参考。为防后缀泄漏，同一事件的不同前缀不得让同一前缀标注者先看到更晚版本。分歧由第三人裁决并保留原始分歧。无法裁定的项目维持 `unknown`。

步骤参考必须由冻结的 SOP 规则判定；需要观察过程的步骤不得仅凭结果端点记完成。牢固度、内部紧固或安全不在本协议标签范围内。

## 5. 当前材料边界、停止条件与下一里程碑

现有公开 q31/q68/q92 只能支持字段级示例和协议边界核对：同一开发事件的三个相关前缀、AI 缓存标签、无独立人工/物理真值。它们不能估计 FCR、拒判覆盖率、样本分母或功效；也不能充当最终验证样本。合成遮挡/移除/身份变化仅是逻辑示例。

真实执行必须先取得授权原视频/原帧、逐帧时间与哈希清单、许可/来源记录，以及盲标参考。旧 IndEgo 119–128 秒真实拆卸原包（原帧 manifest 与 H/F/HF 首答 JSON）目前仍缺；摘要不足以重建它。当前云端仓库没有 Mac 私有素材本体。若三类真实反例任一类缺少可核验来源或独立参考，停止确认性比较；记录为证据不足，不通过扩展合成数据补齐。

**下一里程碑**：只读恢复并哈希核对已存在的真实拆卸原包；随后清点它是否满足分离类要求，以及遮挡保持/对象更换两类是否已有合格原始材料。只有三类材料来源、独立标注和分组均满足后，才冻结最终分母、覆盖率匹配规则与样本量；在此之前不调用模型、不训练、不报告效果。

**唯一当前资料请求**：请提供本机旧 IndEgo 119–128 秒拆卸原包的可读路径或准确 Library 文件名；所指原包需含原帧 manifest 与 H/F/HF 原始首答 JSON。无需现在上传私有媒体。该材料只解除真实分离归档这一项阻塞，不替代另两类反例的准入要求。
