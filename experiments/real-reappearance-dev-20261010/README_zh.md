# StepTrace：真实接口遮挡与再显小试

2026年10月10日｜描述性开发小试｜3份独立首答、零重试

## 这次真正得到什么

在已有真实黑桌装配视频中，找到同一局部接口的一段新变化：

- 69.72秒：远侧黑腿根部与台板的外部相接关系可见
- 69.84秒：目标根部被另一根近侧腿挡住，当前接口关系未知
- 70.08秒：该根部重新可见，外部相接关系再次得到支持

独立视觉复核将它定为B级：前后外部端点有证据，隐藏期间真实关系仍未知。它不是“已经证实全程保持连接”的A级样例，也不证明装牢。图像只在私有研究包中保留；本仓库仅提供来源、时点与哈希。

## 三份首答的实际表现

1. 只给69.72秒：自然建立一条外部连接确认，说明没有看到安装过程
2. 给69.72和69.84秒：自然建立早期确认；当前直接观察记为unknown；在“同一对象、间隙未分离”等明确条件下保留历史，没有因为被挡就撤销
3. 给全部三帧：中间帧仍记unknown；截止重新看见接口后支持当前外部连接，没有虚构拆卸、重装或全程保持

三份结构检查和逐条件独立AI语义复核均通过，原首答未修改。这是同一事件的三个独立上下文前缀，不是三次独立物理实验、不是同一会话的记忆交接，也不能写成“准确率100%”。

遮挡包的历史确实非空，避免了此前遮挡测试没有起始确认、无法观察撤销行为的问题。但本轮只能说明没有把“看不见”直接当成“拆开”；不能据此计算隐藏期保持真值下的误撤销率。

## 与普通状态机的比较

把每份原答逐帧关系和身份标签原样映射成相同事件，交给普通可逆FSM与证据账本；两者三份输出全部相同。遮挡时共同保留历史、直接状态unknown，条件延续为connected；重新可见后恢复直接connected。

一个需公开的字段差异：遮挡首答将条件沿用记录列active；两种确定性表示将当前直接证明列suspended。两者都保留历史且不撤销，因此不能宣称原答与FSM所有字段逐字一致。身份待重验锁没有在这组三帧触发：这里是接口被挡，上半腿仍可见，不是工件离镜头后回来的身份问题。

这轮没有证明新机制胜过普通FSM，也没有支持必须加入长短期神经记忆网络。

## 保留的失败、选择暴露与运行限制

- 两个本地视频各固定12个粗筛时点，再各只检查一个6秒、151原帧窗口
- 白桌候选第三帧仅腿身重现、根部仍被遮挡，未准入，未给模型作答
- 黑桌最初66秒“完全遮挡”判断被否决。69.84秒是同一预冻结窗口里发现的次级事件，属于探索性开发选例
- 源视频曾用于早期开发；这次时点是新输入，但不能称独立测试集。151帧源审没有提供给首答者
- 三份各自自报3次exec，图像各显示一次；实际后台模型、参数、token和费用unknown
- 120秒为软限。一份自报完整起止55.507秒；另两份未记录精确读取起点，如实记unknown，不能补造耗时。图像展示记录为self_report

## 下一步应检验什么

目前可继续用缓存核对“真实分离”和“仅可见性变化”的证据标签及相同规则；不能把隐藏期unknown填成“确定没分离”。要评价真实误撤销率，还需要能独立证明遮挡期间关系保持的样例。要评价跨间隔身份恢复，需要真实离镜头、可能换件、重新核验的材料。

优先研究假设仍是：在相同感知信息、历史和覆盖率下，能否降低误确认与误撤销。现有小试尚未显示普通FSM的缺口，暂不据此启动训练或扩大模型调用。
