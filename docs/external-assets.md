# 外部资产与获取

本发布包不分发任何外部数据、模型或论文全文，也未执行下载。历史代码中的路径与配置只表示输入需求。

1. 从数据集/模型作者或官方发布渠道获取所需版本，按其访问条件与许可使用。未核实来源与再分发权限的本地文件不复制到仓库。
2. 获取后建立本地 manifest，记录官方来源 URL、版本、访问日期、许可/使用条件、文件 SHA-256、任务用途和划分；凭据保存在 Git 之外。
3. 运行前检查 schema、哈希与划分，区分开发、校准与正式 test；缺少来源或身份信息时保持 UNKNOWN 并拒绝正式准入。
4. 论文仅记录出处或官方链接，不随仓库提供全文。

涉及的历史数据集：MECCANO, IndustReal。这份说明不确认其当前下载地址、版本或本地资产合法性。

manifest 模板见 `external-assets.template.json`，仅包含未获取的资产条目；它不是实际数据清单或正式评估凭据。
